JAYEMATH WATER BILLING — V176 FINAL FIX PACKAGE

This package keeps the V176 app features and adds:
1. Mobile login: Super Admin / Staff / Customer roles remain available; service-worker cache is bumped so old mobile PWA code is not silently reused.
2. Customer water-service notifications: cloud water-cut / notice / due-date status is shown in the Customer portal.
3. XP-P301A Bluetooth direct printing: Android native Bluetooth Classic SPP bridge is included in this Android project. Pair the printer in Android Bluetooth settings, then use Printer Setup > Connect XP-P301A.
4. Existing Windows COM / browser printing remains.
5. Existing Staff Security, approvals, email confirmation, edit/correction, tariff, billing, payments, SMS, reports and other V176 options are retained.

Important: the Android native Bluetooth feature requires an Android APK build of this project. The source project is included because this environment cannot compile/sign an Android APK here.
